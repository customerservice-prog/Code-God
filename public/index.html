Connections & setup

1. Connect the coding AI

Start Ollama on this machine and install a coding model with tool support. Then refresh connections. The model runs on your hardware.

Ollama setup guide ↗
2. Enable isolated checks

Start Docker Desktop and preload runtime images in your terminal:

docker pull node:24-bookworm-slim
docker pull python:3.12-slim
3. Optional: private repos & pull requests

Set GITHUB_TOKEN in the server’s .env file and restart. Use a token limited to the repositories you want to edit, with Contents and Pull requests read/write permissions. The token stays on the server.
